# English Fun Start — PWA

Esta carpeta contiene una versión instalable como PWA.

## Importante
Para instalarla en Android como una aplicación, debe servirse desde HTTPS (por ejemplo GitHub Pages, Netlify o Vercel). Abrir `index.html` directamente como archivo no permite que el Service Worker funcione.

## Instalación en Android
1. Publica esta carpeta en un sitio HTTPS.
2. Abre la dirección con Chrome en Android.
3. Pulsa "Instalar aplicación" si aparece el botón, o usa el menú de Chrome → "Instalar aplicación".
4. La aplicación quedará en la pantalla de inicio y funcionará también sin conexión después de la primera carga.

El progreso se guarda localmente en el dispositivo mediante localStorage.
